# Data

(monkey M, session 1). The data are not redistributed here.

1. Request access and download from CRCNS: https://doi.org/10.6080/K0FT8J72
2. Put `MM_S1_processed.mat` anywhere (e.g. Google Drive) and set `CONFIG['MAT_PATH']` in the notebook.
